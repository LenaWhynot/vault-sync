# Синхронизация — справочник навыка vault-s-telefona

Читать: настраиваю автопуш · синк встал · «правки не уехали» · конфликты с
вторым писателем.

## Два задания, один скрипт

| Задание | Период | Делает |
|---|---|---|
| автокоммит | 10 мин | `git add -A` + коммит, БЕЗ push |
| автопуш | 15 мин | fetch → свести с origin → push |

Оба зовут один скрипт (`git_auto.py {commit|push}`) и держат **общий flock**
(`.git/git_auto.lock`): иначе `stash` из push выдёргивает файлы из-под `add` и
получается пустой коммит.

**macOS/launchd:** задание, читающее скрипт из `~/Documents`, обязано идти через
интерпретатор с Full Disk Access (`/opt/homebrew/bin/python3`). `/bin/bash`
упирается в TCC, `Operation not permitted`, и задание молча дохнет с кодом 126.
Проверка живости: `launchctl list | grep <label>` — второй столбец 0, не 126.

## Главный враг — не падение, а молчаливое замирание

Наивный `do_push` на конфликте делает `rebase --abort` и выходит. Если в ветку
пишет кто-то ещё (второй компьютер, сервер, облачный агент), конфликты
неизбежны — и синк встаёт НАСОВСЕМ, без единого сигнала. В живом случае так
простояло 3,5 часа, пока человек не свёл конфликт руками.

Для сценария «работаю с телефона» это отказ: в облаке висит старая версия, и об
этом никто не знает.

## Лесенка вместо стопа

```
1) rebase                  — обычный путь, история линейная
2) merge                   — если rebase уткнулся: он конфликтует покоммитно,
                             merge часто сводится чисто (именно это и делают руками)
3) ветка auto/unsynced     — если и merge не свёлся: main ждёт рук, но локальный
                             HEAD force-пушится туда, и свежий контекст ВСЁ РАВНО
                             виден с телефона. force безопасен: ветку ведёт только скрипт
```

Плюс: лог называет конфликтующие файлы, а со **второго** неудачного тика подряд
приходит уведомление ОС. Счётчик — файл в `.git/`, сбрасывается после успеха.

Уведомление на macOS — текст аргументами, не интерполяцией:

```python
subprocess.run(["osascript", "-e",
                "on run {m, t}\ndisplay notification m with title t\nend run",
                msg, title], check=False)
```

## Журналы, которые дописываются с двух сторон

В `.gitattributes` — `merge=union` для append-журналов (хэндофф, логи, индекс
памяти): параллельные дописки склеиваются вместо конфликта.

## Диагностика

```bash
tail ~/Library/Logs/<...>/auto-push.log     # что именно случилось
git rev-list --count origin/main..HEAD      # сколько не уехало
git ls-remote --heads origin | grep unsynced  # есть — конфликт ждёт рук
```

Если мак выключен — не уезжает ничего. С телефона будет видно состояние на
момент последнего пуша, и это стоит сказать человеку вслух.
