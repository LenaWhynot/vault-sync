# Vault Sync

Работа со своим личным контекстом — папкой знаний для ИИ-агента (правила, память,
голос, проекты) — **с телефона**, когда компьютер выключен и платить за сервер
не хочется.

## Идея

Контекст живёт не на диске, а в **приватном git-репозитории**:

- компьютер синхронизирует его сам — автокоммит + автопуш, с лесенкой на случай
  конфликта (rebase → merge → спасательная ветка), а не молчаливой остановкой;
- с телефона работает **облачный агент** (например Claude Code on the web) — он
  клонирует тот же репозиторий и видит тот же контекст, что и на компьютере;
- работу, сделанную с телефона, компьютер **вливает к себе сам** — облачные
  агенты пушат в свою ветку, и без автослияния она может провисеть неделями,
  дожидаясь, что кто-то нажмёт Merge руками. Здесь это делает планировщик,
  с проверкой на конфликты и списком путей, которые вливать нельзя (всё
  исполняемое: хуки, скрипты, конфиги git).

**Чего это не даёт:** то, что вы намеренно не кладёте в git (сырые личные данные,
секреты, медиа), с телефона недоступно — это граница, а не недоработка.

## Установка

### Как навык Claude Code

```
/plugin marketplace add LenaWhynot/vault-sync
/plugin install vault-s-telefona@vault-sync
```

Агент прочитает [`skills/vault-s-telefona/SKILL.md`](skills/vault-s-telefona/SKILL.md)
и дальше сам разложит по вашему репозиторию — что в git, что нет, как настроить
хуки переносимо, как поставить синхронизацию и автослияние.

### Вручную

Метод и всё рассуждение — в `SKILL.md` и `reference/*.md`. Рабочие скрипты — в
`bin/`, чистый Python (stdlib), без зависимостей:

- **`bin/git_auto.py {commit|push}`** — автокоммит и автопуш.
- **`bin/merge_cloud.py [--dry-run]`** — автослияние веток облачных агентов.

Оба сами определяют путь к репозиторию от своего расположения. Подключить через
планировщик системы: `launchd` на macOS, `cron`/`systemd timer` на Linux —
`commit` каждые 5–10 минут, `push` и `merge_cloud` каждые 15–30.

## Как пользоваться

Своими словами, агенту:

> хочу работать со своей папкой контекста с телефона

> настрой автопуш и автослияние для моего репозитория

> почему правки с телефона не доехали до компьютера
